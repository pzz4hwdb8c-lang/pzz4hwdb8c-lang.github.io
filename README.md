# J.A.R.V.I.S. Power Desk UI

Static login page for the private trading desk.

This repository contains only the front-end bundle and the public Supabase anonymous key.
Account data, positions, trades, and news are not stored here. After login they are loaded from Supabase under row-level security for the owner account.

Chart data is delayed (Yahoo Finance, labeled DELAYED). Demo account only.
